## Manual repository setting

Upload `docs/assets/social-preview.png` in repository Settings → General → Social preview. GitHub does not expose this upload through its public REST API.

## Message hierarchy

1. **Hook:** yellow means a real plan is waiting; red means pinned; blue means ordinary unread.
2. **Proof:** the installer validates the exact official package and runs two isolated 60-second launches.
3. **Safety:** independent copy, no official binaries, no account proxy, no telemetry.
4. **Action:** one PowerShell command.
