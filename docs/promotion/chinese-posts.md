# 中文发布文案

## V2EX 分享创造

标题：

`[分享创造] 做了个 Codex Desktop 多任务增强补丁：黄色=等你确认计划，红色=置顶，蓝色=普通未读`

正文：

> 同时开很多 Codex 任务时，我经常先点开一堆窗口，才想起来哪个在等确认计划、哪个是置顶关注、哪个只是普通未读。官方界面的提示点又很容易混在一起。
>
> 我做了 `codex-desktop-workflow`：它不是新的 Codex 客户端，而是一个本地生成工具。它读取你自己已经安装的官方 Codex Desktop，在独立目录生成一个可验证副本，不覆盖、不替换官方应用。
>
> 主要改动：
>
> - 按任务/进程实际开始时间排序，初次加载和实时更新使用同一规则。
> - 黄色表示真实待实施计划，红色表示置顶关注，蓝色表示普通未读。
> - 远程项目在侧栏、搜索、Work 选择器、提示和无障碍文本中显示可读名称。
> - 已有任务保留有效的模型和推理设置，全局默认只用于新任务。
>
> 安装是一行：
>
> `irm https://github.com/catterhu1207-ux/codex-desktop-workflow/releases/latest/download/install.ps1 | iex`
>
> 安装器会检查官方包、生成本地副本、跑两轮各 60 秒的隔离启动验证，并在前后比较官方 `app.asar`。Release bundle 不包含官方二进制，也不修改商店安装包。
>
> 目前支持 Codex Desktop `26.915.3509.0`，并保留 `26.908.9136.0`。如果你也在多开，欢迎试试并告诉我哪一步最不舒服。
