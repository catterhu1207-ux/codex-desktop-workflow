# 常见问题

## 会替换官方 Codex Desktop 吗？

不会。工具使用你提供的官方包生成独立副本，不修改官方应用目录，并在安装前后比较官方 `app.asar`。

## 支持商店安装版吗？

支持。安装器会向 Windows 查询当前用户安装的 `OpenAI.Codex` 包，并把它的目录作为来源；它不会写入 `WindowsApps`。

## 为什么验证大约需要两分钟？

发布门禁会启动两次隔离副本，每次观察 60 秒，要求出现新鲜 renderer 证明，并通过应用自身的退出动作结束。单次启动成功不足以声明运行已验证。

## 需要重新登录吗？

需要。`-MigrateData` 使用 SQLite 一致性备份复制任务数据，但会排除 `auth.json`、`config.toml`、插件和 skills。请在独立副本内重新登录并配置服务。

## Release bundle 里有 Codex 二进制吗？

没有。bundle 只包含 wheel、安装器、文档和校验和，不包含 `app.asar`、`codex.exe`、补丁后端、用户数据或凭据。

## Codex Desktop 更新后怎么办？

检测到的版本与支持范围不一致时，工具会停止。先运行 `inspect` 查看检测到的版本，然后等待对应版本的 profile，或提交适配 issue。工具不会对未知版本静默改包。

## 和 OpenAI 官方有关系吗？

没有。这是非官方社区项目，不重新分发官方二进制，不代理账号，也不替代官方支持。
