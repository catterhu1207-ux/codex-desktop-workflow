# Roadmap

The roadmap is intentionally small and feedback-driven.

## v0.2.x

- One-command Windows installer with a verified release bundle.
- Bilingual README and landing page.
- Demo assets, FAQ, troubleshooting, and clearer release evidence.

## v0.3 candidates

- Version support for the next exact Codex Desktop package.
- Guided first-run setup after data migration.
- More deterministic Windows installer tests.
- Better issue and troubleshooting templates based on real reports.

## Not planned

- Distributing official Codex binaries or patched backends.
- Replacing the official Store package.
- Removing hash, identity, or two-run verification gates to make a launch pass.
