Install with a supported package

Have Python 3.11 or later, Node.js 22 or later, and available disk space. The installer creates an independent app copy and runs isolated startup checks. The official backend is the default.

irm https://github.com/catterhu1207-ux/codex-desktop-workflow/releases/latest/download/install.ps1 | iex

For an uninstalled complete x64 MSIX, download install.ps1 from the release page and pass -Source with its file path. Its internal version must be supported.

Your official app stays in place. Existing chats require explicit data import and signing in again; the two apps then keep separate data without automatic synchronization.

The 26.1007.9446.0 profile runs three isolated launches, each observed for at least 60 awake seconds. Copying, startup and checks add time; wait for completion.
