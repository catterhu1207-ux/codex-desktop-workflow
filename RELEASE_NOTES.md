# v0.3.10 — Desktop 26.1016.8120.0

This release adds an independent adapter for the complete official Windows x64 package **26.1016.8120.0**. Supply a matching signed MSIX or official application directory; a Store installation is not required.

Priority and activity lists put recent chat activity first. Opening an old chat preserves its position, and a new completed reply moves it forward. Manual pin order and saved chat settings survive a restart. Native first messages, Codex and Work projects, real SSH routing, file drops and 400-chat pagination passed isolated interface checks with both backend modes.

Window hiding and restoration now retain the same-run feature proof, so a background test window can report completion after it is restored. The acceptance receiver rejects mixed identities and incomplete proof records.

The official backend remains the default. The optional compatibility backend builds from pinned public source for `0.163.0-alpha.11.1.1`, using Rust 1.99.1 and all 77 official database migration checksums. Existing published profiles retain their identities.

See the [acceptance report](https://github.com/catterhu1207-ux/codex-desktop-workflow/blob/main/ACCEPTANCE.md) for source, runtime and downloaded-installer results.
